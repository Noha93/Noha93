# طوارئ (Tawari') — تطبيق إبلاغ عن الطوارئ في مصر

تطبيق React Native (Expo Router + TypeScript) بيسمح للمستخدم إنه يبلّغ فورًا عن حريق أو سرقة/جريمة أو حالة طبية طارئة بضغطة زر واحدة، مع مشاركة موقعه الجغرافي بسهولة مع الجهة المختصة أو مع جهات اتصاله الشخصية.

## تشغيل المشروع

```bash
cd tawari-app
npm install
npx expo start
```

افتحي التطبيق على موبايلك عن طريق تطبيق **Expo Go** (امسحي الـ QR code)، أو شغّليه على محاكي:

```bash
npm run android   # يحتاج Android Studio / محاكي Android
npm run ios       # يحتاج macOS + Xcode
```

> ملاحظة: الاتصال الحقيقي (`tel:`) والـ GPS ومشاركة واتساب/SMS محتاجين جهاز حقيقي أو محاكي بيحاكي الاتصالات — بعض الميزات دي بتتصرف بشكل محدود على المحاكيات.

## البنية

```
app/                      # شاشات Expo Router (file-based routing)
  _layout.tsx              # الـ Root layout: تحميل الخطوط + الـ Providers
  (tabs)/_layout.tsx        # الـ bottom tabs (الرئيسية / الخريطة / السجل / الإعدادات)
  (tabs)/index.tsx          # الشاشة الرئيسية: أزرار SOS + خدمات أخرى + جهات الاتصال
  (tabs)/settings.tsx       # إدارة جهات اتصال الطوارئ (حتى 5)
  (tabs)/history.tsx        # سجل البلاغات والمكالمات (محلي على الجهاز)
  (tabs)/map.tsx            # placeholder لمرحلة تانية (خريطة أقرب نقاط الإنقاذ)

src/
  constants/                # الألوان والخطوط والمسافات + بيانات أرقام الطوارئ المصرية
  context/                  # ContactsContext / ReportsContext / ToastContext (AsyncStorage)
  hooks/useLocation.ts       # GPS عبر expo-location
  utils/share.ts             # بناء رسالة الطوارئ + واتساب/SMS/Share Sheet/نسخ رابط
  components/                # SosButton, BottomSheet, الشيتات المختلفة...
```

## الـ Flow الأساسي

1. **زر SOS (حريق/شرطة/إسعاف)**:
   - ضغطة عادية → شيت تأكيد بلاغ (بلاغ رقمي محاكاة داخل التطبيق، أو اتصال مباشر بالرقم الرسمي).
   - ضغط مطوّل **3 ثوانٍ** → اتصال فوري بالرقم الرسمي + بعد رجوعك للتطبيق، فتح تلقائي لمشاركة الموقع عبر واتساب (المستخدم لسه بيختار جهة الاتصال يدويًا — واتساب مش بيسمح بإرسال تلقائي لحد بدون تدخل المستخدم).

2. **أي اتصال هاتفي فعلي** (SOS أو خدمة تانية زي الغاز/الكهرباء) لازم يفضل عليه **شيت تأكيد إجباري** قبل فتح الـ dialer.

3. **بعد إنهاء مكالمة SOS** (بيتم رصدها لما التطبيق يرجع لل foreground):
   - "هل تم حل المشكلة؟" → **نعم**: يتقفل كل حاجة. **لا**: بيفتح شيت "شارك موقعك" بأربع طرق:
     - 🟢 واتساب (رسالة جاهزة + رابط خرائط، والمستخدم يختار المستلم)
     - 💬 SMS (بيفتح composer النظام مع جهات اتصال الطوارئ المحفوظة كـ recipients جاهزين)
     - 📱 Share Sheet النظام (لأي تطبيق تاني)
     - 📋 نسخ رابط الموقع

## قرارات مقصودة (زي ما مطلوب في CLAUDE.md الأصلي)

- **مفيش تكامل حقيقي مع أنظمة الشرطة/الإسعاف المصرية الرسمية.** "البلاغ الرقمي" جوه التطبيق محاكاة للعرض بس. الاتصال الحقيقي الوحيد هو `tel:` بالأرقام الرسمية.
- **مفيش إرسال SMS/واتساب تلقائي صامت لحد.** ده قيد فعلي في iOS وAndroid — التطبيق بيجهّز الرسالة والمستلمين المقترحين لكن المستخدم لازم يضغط "إرسال" بنفسه.
- **RTL:** التطبيق مصمم يدويًا كـ RTL (زي الـ HTML prototype بـ `dir="rtl"`) من غير الاعتماد على `I18nManager.forceRTL` (اللي بيحتاج إعادة تشغيل التطبيق ليشتغل صح) — عشان كده كل الـ layouts متبنية يدويًا بـ `flexDirection: row-reverse` + `textAlign: right`.
- **الخطوط:** Cairo (العناوين) + Tajawal (النص الأساسي) عبر `@expo-google-fonts`.

## المرحلة الجاية (Should/Could)

- العمل بضعف الإنترنت عبر SMS احتياطي بدل الإنترنت.
