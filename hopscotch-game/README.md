# لعبة الحجلة (Hopscotch)

لعبة حجلة رقمية باستخدام HTML5 Canvas — من غير أي مكتبات أو build step، تفتح مباشرة في المتصفح.

## طريقة التشغيل

افتحي `index.html` في أي متصفح، أو شغلي سيرفر بسيط:

```bash
cd hopscotch-game
python3 -m http.server 8000
```

وبعدين افتحي `http://localhost:8000`.

## طريقة اللعب

- الشبكة مرسومة على شكل الحجلة الكلاسيكي (مربع، مربع، مربعين جنب بعض، ...) من 1 لـ 10.
- كل جولة، حجر 🪨 يترمى على مربع عشوائي — لازم تتخطاه من غير ما تلمسيه.
- اضغطي **مسافة (Space)** أو دوسي على الشاشة عشان تجهزي للنطة، وتاني ضغطة تنطي.
- في شريط تحت فيه علامة بتتحرك — اضغطي وقت ما تكون داخل المنطقة الخضرا (أوسع في المربعات المزدوجة لأنك بتنطي برجلين).
- لو لمستي الخط تخسري محاولة (❤️)، وبعد 3 محاولات ضايعة تخلص اللعبة.
- كل جولة كاملة (رايح وجاي) بتزود الصعوبة والنقاط.

## الملفات

- `index.html` — الواجهة والـ overlays (شاشة البداية / نهاية اللعبة)
- `style.css` — التنسيق
- `game.js` — منطق اللعبة والرسم بالـ Canvas (state machine + game loop)
