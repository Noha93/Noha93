# نظام التصميم (Design System) — تطبيق زي (Zey)

## 1. هوية العلامة
- **الاسم**: زي — Zey (بمعنى "الزي/الأناقة" بالعامية المصرية، اسم قصير يعمل بالعربي والإنجليزي).
- **الشخصية**: عصري، دافئ، واثق، بسيط (Minimal but warm) — يناسب العائلة كلها وليس فقط فئة واحدة.
- **الاتجاه**: RTL أساسي (عربي) مع دعم كامل LTR (إنجليزي).

## 3. الطباعة (Typography)
- **خط العربي**: Cairo / Tajawal (للعناوين والنصوص).
- **خط الإنجليزي/الأرقام**: Inter.

| Style | الحجم | الوزن | الاستخدام |
|---|---|---|---|
| Display | 32px | Bold (700) | شاشات ترحيبية كبيرة |
| H1 | 24px | Bold (700) | عناوين الصفحات |
| H2 | 20px | SemiBold (600) | عناوين أقسام فرعية |
| Body-L | 16px | Regular (400) | نص أساسي |
| Body-M | 14px | Regular (400) | وصف المنتج، تفاصيل |
| Caption | 12px | Medium (500) | تسميات، وسوم الأسعار القديمة |
| Button | 16px | SemiBold (600) | نص الأزرار |

Line-height: 1.4× لحجم الخط. تباعد الحروف الافتراضي.

## 4. نظام المسافات والشبكة (Spacing & Grid)
- شبكة أساسها **8px** (Base unit = 8).
- المقاييس: `4, 8, 12, 16, 24, 32, 40, 48, 64`.
- هوامش الشاشة (Screen margin): 16px.
- شبكة المنتجات: عمودين (2-column grid) بفجوة 12px، مع خيار عرض عمود واحد (List view).

## 5. زوايا الاستدارة والظلال
| Token | القيمة |
|---|---|
| `radius/sm` | 8px (أزرار صغيرة، وسوم) |
| `radius/md` | 12px (بطاقات المنتج، الحقول) |
| `radius/lg` | 20px (Bottom sheets، بطاقات كبيرة) |
| `radius/pill` | 999px (فلاتر Chips، شارات) |

| Elevation | الاستخدام |
|---|---|
| `shadow/1` | بطاقات المنتج (خفيف جدًا) |
| `shadow/2` | شريط تنقل سفلي، Bottom sheet |
| `shadow/3` | Modals، عناصر عائمة (زر السلة) |

## 6. الأيقونات
- أسلوب Line icons بسمك خط 1.5px، زوايا مستديرة قليلاً، حجم أساسي 24×24px.
- أيقونات خاصة: قلب (مفضلة)، سلة، فلتر (خطوط أفقية بمؤشرات)، مقاس (مسطرة)، شحن (شاحنة)، إرجاع (سهم دائري).

## 7. المكونات الأساسية (Core Components)

### الأزرار (Buttons)
- **Primary**: خلفية `brand/600`، نص أبيض، radius/sm، ارتفاع 48px.
- **Secondary**: حدود `brand/600` بدون تعبئة، نص `brand/600`.
- **Ghost/Text**: بدون حدود، للإجراءات الثانوية (مثل "تخطي").
- الحالات: Default / Pressed (تعتيم 10%) / Disabled (neutral/300) / Loading (Spinner).

### حقول الإدخال (Inputs)
- ارتفاع 48px، radius/md، حدود `neutral/300`، عند التركيز حدود `brand/600` + ظل خفيف.
- تسمية عائمة (Floating label) + نص مساعد/خطأ أسفل الحقل.

### بطاقة المنتج (Product Card)
- صورة بنسبة 3:4، اسم المنتج (سطرين كحد أقصى)، السعر (مع سعر مشطوب إن وجد خصم)، أيقونة قلب أعلى يمين الصورة، شارة خصم أعلى يسار الصورة عند الحاجة.

### شرائط التنقل
- **Bottom Tab Bar**: 5 عناصر (الرئيسية، تصفح، المفضلة، السلة مع عداد، الحساب)، ارتفاع 64px + Safe area.
- **Segmented Control** (أعلى صفحة "تصفح"): نساء / رجال / أطفال — تبديل فوري مع الحفاظ على حالة الفلاتر لكل قسم.

### الفلاتر (Filter Chips)
- Chips بشكل Pill، حالة مفعّلة بخلفية `brand/100` ونص `brand/600`، مع عداد نتائج ظاهر دائمًا في زر "تطبيق الفلاتر".

### شارات الحالة (Badges)
- خصم: خلفية `accent/coral`، نص أبيض، Caption.
- جديد: خلفية `color/section/*` حسب القسم.
- نفاد المخزون: خلفية `neutral/100`، نص `neutral/500`.

### Bottom Sheets
- تُستخدم لاختيار المقاس/اللون، الفلاتر، ومشاركة المنتج — radius/lg من الأعلى، مقبض سحب (Drag handle) أعلى المنتصف.

## 8. أوضاع خاصة (States)
- **Empty state**: رسم توضيحي بسيط + نص ودّي + CTA (مثال: سلة فارغة → "لسه ماخترتيش حاجة؟ يلا نتصفح").
- **Error state**: أيقونة تحذير + رسالة واضحة بدون مصطلحات تقنية + زر إعادة المحاولة.
- **Loading**: Skeleton screens لبطاقات المنتج بدل Spinner كامل الشاشة.

## 9. دعم RTL
- كل الأيقونات الاتجاهية (سهم رجوع، سهم "التالي") تُعكس تلقائيًا في RTL.
- محاذاة النص لليمين، وترتيب عناصر الشريط السفلي والعلوي معكوس اتجاهيًا لا بصريًا (الأيقونات نفسها تبقى بصرياً كما هي إلا الاتجاهية).

## 10. أسماء رموز التصميم (Naming Convention) في Figma
`color/*`, `type/*`, `space/*`, `radius/*`, `shadow/*` — Variables/Styles منظمة كمجموعات ليسهل استخدامها كـ Design Tokens قابلة للمزامنة مع الكود لاحقًا.
