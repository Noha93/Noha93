# مطاعم البشوات — الموقع الإلكتروني

موقع احترافي متجاوب لسلسلة مطاعم البشوات، مبني بـ Next.js 14 (App Router) + TypeScript + Tailwind CSS + Prisma/PostgreSQL.

## المميزات
- صفحات: الرئيسية، من نحن، المنيو (بتصنيفات وأسعار)، العروض، الفروع (بخرائط جوجل ومواعيد)، الطلب أونلاين، تواصل معنا، الأسئلة الشائعة.
- سلة مشتريات (Zustand) + إرسال الطلب لقاعدة البيانات ثم تحويل تلقائي لواتساب الفرع بملخص الطلب (بدون بوابة دفع — الدفع عند الاستلام حسب اختيار العميل).
- لوحة تحكم (`/admin`) محمية بتسجيل دخول (JWT في كوكي httpOnly) لإدارة المنيو والأقسام والعروض والفروع، وعرض الطلبات ورسائل التواصل.
- SEO: `sitemap.ts`، `robots.ts`، Metadata لكل صفحة، JSON-LD لـ Restaurant وFAQPage.
- تصميم RTL بالكامل بخط Cairo، ومتجاوب مع الموبايل والتابلت والديسكتوب.

## التشغيل محلياً
```bash
npm install
cp .env.example .env   # عدّلي DATABASE_URL وباقي القيم
npx prisma migrate dev --name init
npm run prisma:seed    # بينشئ حساب أدمن تجريبي + بيانات تجريبية
npm run dev
```

بيانات دخول الأدمن الافتراضية بعد الـ seed: القيم في `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD` بملف `.env` (لازم تتغيّر قبل أي نشر حقيقي).

## قبل النشر (Production)
- غيّري `ADMIN_SESSION_SECRET` لقيمة عشوائية طويلة، وغيّري كلمة مرور الأدمن الافتراضية.
- اربطي `DATABASE_URL` بقاعدة بيانات PostgreSQL حقيقية (مثل Supabase / Neon / RDS).
- ارفعي صور المنيو والعروض على خدمة تخزين (S3 / Cloudinary) واستخدمي الروابط في لوحة التحكم.
- استضيفي المشروع على Vercel أو أي منصة تدعم Next.js، واربطي الدومين الفعلي.
