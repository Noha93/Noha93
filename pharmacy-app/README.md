# صيدليتي — Pharmacy App

تطبيق ويب تفاعلي كامل لصيدلية إلكترونية مصرية، بجزأين:

- **📱 تطبيق العميل** — تصفح الأدوية ومستحضرات العناية، بحث بالاسم التجاري أو المادة الفعالة، رفع روشتة، سلة مشتريات، إتمام طلب، تتبع الطلب، واستشارة صيدلي عبر شات مباشر أو واتساب.
- **🖥️ داشبورد الإدارة** — تسجيل دخول، لوحة تحكم بمؤشرات الأداء، إدارة المنتجات والمخزون، مراجعة الطلبات والروشتات، تحليلات المبيعات، ومعدل صرف الأدوية الشهري.

التصميم مبني على نظام تصميم Figma (ألوان وخطوط Cairo/Tajawal، واجهة RTL بالكامل) ومطابق لدراسة حالة UX/UI الخاصة بالمشروع.

## التشغيل محليًا

التطبيق صفحة ويب ثابتة (HTML/CSS/JS بدون تبعيات) — يكفي فتح `index.html` في المتصفح، أو تشغيل خادم بسيط:

```bash
cd pharmacy-app
python3 -m http.server 8080
# افتح http://localhost:8080
```

## البنية

```
pharmacy-app/
├── index.html   # هيكل الصفحة (تطبيق العميل + داشبورد الإدارة)
├── style.css    # التصميم الكامل (توكنز الألوان، الخطوط، المكوّنات)
└── script.js    # منطق التطبيق (بيانات المنتجات، التنقل بين الشاشات، السلة، الداشبورد)
```

## بيانات الدخول التجريبية (داشبورد الإدارة)

أي بريد إلكتروني وكلمة مرور يعملان — الشاشة عرض تجريبي (Prototype) وليست متصلة بخادم فعلي.
